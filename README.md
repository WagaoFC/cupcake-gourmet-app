Projeto desenvolvido para a disciplina de **Projeto Integrador Transdisciplinar em Engenharia de Software II** da Cruzeiro do Sul Virtual.

- **Arquitetura:** MVC (Model-View-Controller)
- **Tecnologias:** Node.js, Express, Sequelize (ORM), MySQL, EJS, Jest (Testes)

## 🚀 Como Executar o Projeto localmente
1. Instale as dependências: \`npm install\`
2. Configure as variáveis no banco de dados.
3. Inicie o servidor: \`npm start\`
4. Rode os testes unitários: \`npm test\`
